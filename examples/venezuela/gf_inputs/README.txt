The published Venezuela inversions read regional Green's functions computed on
2026-07-30, before the regional velocity-model rule changed (the earlier rule
removed only the water layer; the current one also removes sediments with
Vs < 2 km/s). vmodel_loc here is that earlier model, rebuilt from the CRUST1.0
column with the earlier rule. Regenerated regional Green's functions match the
published start times exactly and the waveforms to ~2% (the remaining
difference comes from an earlier version of the fk scripts); the resulting
moment tensors agree with the published ones to the printed precision.
